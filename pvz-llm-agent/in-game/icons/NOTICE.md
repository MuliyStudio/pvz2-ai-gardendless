# 界面图标来源与许可

`in-game/ui.js` 里的内联 SVG 图标来自 **Lucide**（https://lucide.dev），版本 `lucide-static@0.468.0`：

- 思考窗、缩小、清空、关闭、测试、开始、停止、导出、导入、复制、折叠箭头
- 只内联了 path 数据，不依赖外部字体、图片或网络请求
